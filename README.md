# Future News App Store pages

This repository hosts the public support, privacy policy, and marketing pages for Future News on GitHub Pages.

| App Store Connect field | URL |
| --- | --- |
| Marketing URL | https://zackdallen.github.io/future-news-app-store/ |
| Support URL | https://zackdallen.github.io/future-news-app-store/support/ |
| Privacy Policy URL | https://zackdallen.github.io/future-news-app-store/privacy/ |

GitHub Pages publishes directly from the root of the `main` branch. To preview locally, run `python3 -m http.server 4179` here and open the loopback address on port 4179.
